The Twin Test

Our network remembers the way home by rewriting its own connections. Its twin is the same network with that part removed and a gate that lets its neurons hold their activity instead. Same size, same inputs, same training. Which one homes better, and when?

The two twins

Both networks are the same machine. Each has 64 neurons. Each tick (a tenth of a second) they receive four numbers: the heading as two numbers (east–west and north–south parts), the walking speed, and whether food is underfoot. Each tick they produce a turn command. Between the neurons sits a table of connection strengths called W, set by training and then frozen. Everything so far is identical.

The difference is how a number is kept over time. The fly needs to keep a running total of where it has walked, so it can turn around and walk back.

  1. Our network (FW, for fast weights) keeps the total in a second table of connection strengths, the board F, that it rewrites every tick. A write gate decides how much to add; an erase gate decides how much to wipe. A table called A (4,096 numbers) decides how much each board cell matters. This is the fly's proposed trick.
  2. The twin (TWIN) has no board. Instead each neuron has a hold gate u between 0 and 1. Each tick the neuron's new value is (1 − u) × old value + u × new proposal. With u at 0 it keeps its old value exactly. With u at 1 it behaves like our network's plain neurons. The gate's weights are 4,416 numbers, close to A's 4,096.

Sketch, not data

Why this is the fair version of the question. The roadmap's argument was that a memory held in activity has to repeat its number to itself with a loop gain of exactly 1 (multiply by exactly one each tick), which is hard to get right, while a tally in the connections just sits there. The twin is handed a gate that can hold at exactly 1. So the question becomes: does it learn to use it?

Sizes: FW 8,708 trained numbers; TWIN 9,027 (4% more). A textbook GRU (a standard gated memory network) with 52 memory units, 9,101 numbers, runs beside them as a reference, never used to decide the verdict.

How to read the charts

Every score on this page is the same ruler as the first two nights. The fly walks out for a while with its steering ignored, then has twice that long to walk home using its own turn commands. The score is the closest it ever gets to home, in the same units as the walk (a unit is about what the fly covers in one second), averaged over 200 test trips. Lower is better. The hand-built fly brain scores about 0.75. A fly that never steers scores about 4.4.

Each dot is one trained network. Networks in the same row were trained the same way and differ only in the random numbers they started with (the seed). The thin bar through a dot is that network's own exam noise: if we gave it 200 different trips, its score would land inside the bar 95 times in 100. The thick tick is the row's average.

Sketch, not data

The rule for calling a winner was written before anything ran:

  1. Take the average of each row.
  2. If the averages differ by less than 0.2, it is a tie. With three or four networks per row, a gap that small could come from training luck alone (night two measured the plain recipe's seed-to-seed spread at 0.16).
  3. If they differ by 0.2 or more and no dot of one row overlaps the other row's range, that row is better.
  4. If they differ by 0.2 or more but the ranges overlap, it leans better.

The long stop

This is the roadmap's central argument, turned into a test. The fly walks for 15 seconds, stands still for 10 or 30 seconds, then walks another 15 seconds and turns for home. It walks exactly as far as on the standard exam; only the standing is added. A tally in the connections has nothing to do while standing. A memory in activity has to hold its number for the whole stop.

Five trips in a row

The plan's "two food sites" test becomes this in our world: five trips back to back, and the score of each trip. A clean wipe at food means trip five scores like trip one. This test is not a contest. The world wipes every network's activity at the start of each trip for free. The twin gets its reset from the world; our network has to earn its reset with its erase gate, because the board is not wiped. So this chart shows what the reset costs our network.

Learning from scratch

The warm twins inherited our network's history: its compass cells, its connection table, everything but the board. The cold pair asks a different question. Start both designs from random numbers, give them the same lessons in the same order, and see which one learns. The lessons are the curriculum from the first night: 10-second wanders until the running score drops under 1.5 (or 1,500 iterations pass), then 20 seconds, then 30.

The trap in the loss

Training does not see the score. It sees the loss: the average distance from home over the last 10 seconds of the return. For a network that cannot yet remember anything, those two disagree. Here is how, step by step.

  1. A fly with no memory has no idea where home is when it turns around.
  2. If it keeps walking, it wanders further away. By the last 10 seconds of the return it is far from home.
  3. If it spins on the spot at full lock, it stays roughly where it turned. It never gets closer, but it never gets further either.
  4. So spinning gives a much lower loss than walking, even though it homes worse. Training follows the loss, so a network without a memory is pulled towards spinning, and once it spins, small changes do not help, so it stays there.
  5. A network that already holds a usable tally escapes: reading the tally and walking home beats spinning. Our network's board starts collecting a tally on the very first tick without any training. An activity network has to discover how to hold a number first, and the pull towards spinning works against it the whole time.
