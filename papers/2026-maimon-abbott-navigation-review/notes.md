# Maimon & Abbott (2026): functional logic of navigation

[Review](https://doi.org/10.1146/annurev-neuro-112723-062711) · [Author PDF](https://maimonlab.rockefeller.edu/wp-content/uploads/2026/07/Maimon-and-Abbott-Functional-Logic-of-a-Cognitive-Brain-System-for-Navigation.pdf)

This is a provisional review note, not a completed figure-level reading.

The review connects the compass, body-to-world velocity transformation and goal-to-steering transformation using Marr’s computational, algorithmic and implementation levels. Its strongest synthesis concerns instantaneous angular/vector computations. Its memory architecture remains a proposal: columnar populations could store vectors, with tangential neurons controlling which influences FC2.

Figure 5 deliberately mixes hypotheses, preliminary cAMP imaging, and schematic calcium spikes; it must not be treated as a demonstrated food-location memory circuit. The appendix explains cancellation of unwanted terms when symmetric inputs pass through an approximately quadratic nonlinearity. That robustness argument does not establish arbitrary nonlinearities as interchangeable.

Priority reference trails: dopamine/octopamine-dependent compass learning; visual/vestibular-equivalent cue reliability; recurrent goal storage; food-triggered local search and odometry; descending steering; and the distinction between fly evidence and ant/bee vector-memory models.

Publication-year differences matter: the review cites preprint/online dates for several papers whose final versions are already represented elsewhere in this repository.
