# Paper library

Each paper gets its own folder. `metadata.json` records sources and assets; `notes.md` holds analysis; `reading-log.md` records exactly which text, figures, and supplementary assets were read. PDFs and supplements belong beside the notes. Missing assets or incomplete reading must remain explicit.

Detailed reading is in progress. The broad [literature map](../docs/literature.md) is a discovery index, not a substitute for full-paper review.
